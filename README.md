# Project Details
Impact Odyssey is a comprehensive platform developed for the NASA Space Apps Challenge to make complex astronomical data on Near-Earth Objects (NEOs) accessible and understandable. 
Its core mission is to empower informed decision-making for planetary defence by offering a suite of advanced tools, including real-time orbital visualizations and interactive 3D simulations. 

The platform allows users to visualize the asteroid data and study various orbital elements via tooltips, run "what-if" scenarios, enabling the calculation of potential damage effects, such as crater diameter, fireball radius, and tsunami height, and evaluation of mitigation strategies like trajectory deflection.
